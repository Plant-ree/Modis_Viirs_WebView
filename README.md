# How to use
Alright so there are some keyboard/mouse inputs. 
### 1. Left click
   Click once and that will be the starting point of your polygon, click again to make the first line, and so on. You cannot clip lines.
### 2. Right click
   Once you have your desired polygon (you don't have to make the last edge of the polygon, this will auto-complete it for you), simply right click and a polygon will be formed where the fire information will be displayed.
### 3. Ctrl + Z
   Remove previous polygon edge, if you have just one edge, press ctrl + z twice to also remove the initial point (will make it so both points of the first edge are removed if this is inconvenient or unclear for newer users)
